# Grecia Barragán Páez — Portfolio

A simple static portfolio built with HTML and CSS.

## Edit the site

Open `index.html` in GitHub and click the pencil icon, or clone this repository and edit it with VS Code. The photo and video placeholders include comments showing where to add files and which filenames to use.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub Pages will provide the published URL on that settings page after deployment finishes.
